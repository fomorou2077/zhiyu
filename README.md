# 知舆 ZhiYu — 普惠型 AI 舆论监测与审辩思维平台

> 让中小企业和内容创作者也能用得起的智能舆情工具：提前发现风险、科学应对危机、理性辨别信息。

---

## 产品介绍

### 我们解决什么问题

在信息爆炸的时代，舆论风险无处不在，但**传统舆情服务和公关公司的高昂费用，让绝大多数中小企业和自媒体创作者望而却步**：

- **风险发现滞后**：负面舆情发酵后才被动知晓，错过最佳应对窗口
- **人工筛查效率低**：海量内容靠人工逐条判断，耗时耗力且容易遗漏
- **应对缺乏指导**：危机发生后不知道该怎么回应，只能凭感觉处理
- **信息真假难辨**：内容创作者面对海量信息，缺乏高效的审辩工具

知舆要做的，就是**把昂贵的舆情服务和审辩能力，变成人人都能用得起的 AI 工具**。

### 双版本设计

知舆采用同一代码库、双版本切换的架构：

| 版本 | 面向用户 | 核心价值 |
|------|---------|---------|
| **企业版** | 中小企业、品牌运营者 | 低成本舆情监测中台：多平台监测、风险预警、传播追踪、回应建议、一键报告 |
| **个人版** | 自媒体创作者、内容从业者 | AI 审辩思维助手：事实核查、逻辑谬误识别、信源交叉验证、立场光谱分析、深度伪造检测 |

### 核心亮点

- **风险提前预警**：基于 AI 模型预测舆情发展趋势，提前识别潜在风险
- **全流程闭环**：从监测、分析、预警到处置建议，一站式完成
- **多模态分析**：支持视频语音转写、情绪分析、文本审辩等多种内容形态
- **开箱即用**：一键启动，无需复杂配置，个人和小团队也能快速上手

## 应用场景

### 🏢 中小企业品牌舆情监测

一家初创公司的新品发布后，在社交媒体上出现了零星负面评价。知舆可以：

- 实时监测小红书、抖音、B站等平台的品牌提及和评论情绪
- 在负面声量异常上升时自动预警，提前介入
- 追踪传播路径，找到关键传播节点
- AI 生成多种回应方案供选择，避免"越描越黑"
- 一键导出舆情分析报告，用于内部复盘和向上汇报

### 🎬 自媒体创作者内容审辩

一位知识类博主在做热点事件选题时，面对网上众说纷纭的信息，知舆可以：

- 对事件相关文本进行事实核查，标注信息来源可靠性
- 识别内容中的逻辑谬误和论证漏洞
- 多语言交叉验证，打破信息茧房
- 立场光谱分析，呈现不同阵营的观点分布
- 帮助创作者输出更客观、更有深度的内容

### 📊 品牌公关与危机应对

企业遭遇突发舆论危机时，知舆可以：

- 快速汇总事件相关的全网讨论和情绪倾向
- 生成法律证据包（截图、转录、时间戳、传播数据），满足合规存证需求
- 提供 5 种不同策略的回应文案，辅助决策
- 持续监测危机后续发展，评估应对效果

### 🎓 学术研究与教学

高校新闻传播、公共关系相关专业可以：

- 使用内置的 50+ 经典舆情案例库进行教学分析
- 利用多模态情绪分析工具研究视频内容的传播效果
- 通过模拟推演功能观察不同回应策略的舆论走向

## 核心功能

### 企业版 · 舆情中台

| 功能 | 说明 |
|------|------|
| **多平台监测** | 模拟抓取小红书、抖音、B站等平台内容表现数据，追踪传播效果 |
| **AI 风险预警** | 基于内容标签、历史热度曲线和创作者影响力，预测未来热度走势 |
| **传播追踪** | 可视化传播路径网络图，定位关键传播节点 |
| **竞品分析** | 管理监测竞品品牌，对比声量和情绪趋势 |
| **智能回应生成** | 一键生成 5 种不同策略的回应文案，支持批量生成 |
| **一键报告** | 对接 Coze 工作流，输入事件概述即可生成结构化舆情报告 |
| **法律证据包** | 自动生成含截图、转录、时间戳、传播数据的 ZIP 证据包 |
| **策划方案评估** | 上传策划文档，AI 从合规性、舆情风险、受众接受度等 10 维度评估 |

### 个人版 · 审辩思维

| 功能 | 说明 |
|------|------|
| **事实核查** | 对文本内容进行事实性核查，标注可靠信源 |
| **逻辑谬误识别** | 自动识别论证中的逻辑漏洞和谬误类型 |
| **多语言交叉验证** | 跨语言检索多方信源，验证信息一致性 |
| **立场光谱分析** | 呈现事件相关观点的立场分布，打破信息茧房 |
| **深度伪造检测** | 图片/视频深度伪造检测（占位，持续完善中） |

### 共享能力

- **视频情绪分析**：上传视频，自动语音转文字，AI 分析 7 维度情绪倾向，生成可视化雷达图
- **观点对冲解读**：针对同一事件，AI 自动搜索多方观点对比分析
- **AI 关怀助手「知知」**：基于大模型的对话助手，提供创作激励、情绪支持与热点解读
- **媒体可靠性评级**：评估媒体来源的公信力等级
- **秘塔搜索集成**：内置实时信息检索，辅助内容核查
- **舆情案例库**：内置经典舆情事件深度分析报告，支持一键下载 .docx 原文

## 快速开始

### 环境要求

| 依赖 | 版本要求 | 说明 |
|------|---------|------|
| Python | 3.8+ | 推荐 3.10 |
| ffmpeg | 任意版本 | 视频音频提取必需 |
| Vosk 模型 | cn-0.22 | 离线语音识别（需单独下载至 `models/`） |

### 安装 ffmpeg

**Windows**
```bash
winget install ffmpeg
```

**macOS**
```bash
brew install ffmpeg
```

**Linux (Ubuntu/Debian)**
```bash
sudo apt update && sudo apt install ffmpeg
```

### 1. 克隆项目

```bash
git clone <repo-url> 知舆
cd 知舆
```

### 2. 创建虚拟环境并安装依赖

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

> 如遇网络问题，可使用阿里云镜像：
> ```bash
> pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
> ```

### 3. 配置环境变量

```bash
cp .env.example .env
```

编辑 `.env`，填入必要的 API 密钥：

| 配置项 | 必需 | 说明 |
|--------|------|------|
| `DASHSCOPE_API_KEY` | **是** | 阿里云百炼 API Key（[获取地址](https://dashscope.console.aliyun.com/apiKey)） |
| `SECRET_KEY` | **是** | JWT 签名密钥（可随机生成） |
| `COZE_API_URL` | 否 | Coze 工作流地址（报告生成功能需要） |
| `COZE_API_TOKEN` | 否 | Coze 访问令牌 |
| `METASO_API_KEY` | 否 | 秘塔搜索 API Key |
| `MIROFISH_BASE_URL` | 否 | MIROFISH 模拟推演服务地址 |

### 4. 启动服务

**一键启动（推荐，Windows）：**
```bash
start_backend.bat
```

**手动启动：**
```bash
python run.py
```

服务默认运行在 `http://localhost:8000`。

### 5. 开始使用

- 打开浏览器访问 `http://localhost:8000/`，选择个人版或企业版
- API 文档（Swagger）：`http://localhost:8000/docs`

## 多模态情绪分析（可选高级功能）

项目内置实验性三模态情绪分析模型，融合视觉（ResNet50）、音频（Wav2Vec2）和文本（BERT）特征联合推理。

**额外依赖：**
```bash
pip install torch torchvision torchaudio transformers opencv-python librosa pandas tqdm
```

**训练流程：**
```bash
# 步骤1：数据准备
python scripts/prepare_data.py --data-dir uploads --max-videos 100

# 步骤2：模型训练
python scripts/train_multimodal.py --batch-size 4 --epochs 30
```

**模型架构：**
```
MultiModalEmotionModel
├── VisualEncoder (ResNet50)   → 视觉特征 2048-d
├── AudioEncoder (Wav2Vec2)    → 音频特征 768-d
├── TextEncoder (BERT)          → 文本特征 768-d
└── CrossModalAttention         → 融合特征 → 7 维情绪输出
```

## 常见问题

**Q: 启动报错 `ModuleNotFoundError: No module named 'vosk'`**
Vosk 是语音识别核心依赖。检查 `pip install vosk` 是否成功。Windows 用户可能需要安装 Visual C++ Redistributable。

**Q: 情绪分析返回空或报错**
检查 `.env` 中的 `DASHSCOPE_API_KEY` 是否正确配置。运行 `python scripts/check_key.py` 诊断。

**Q: 视频上传后语音转写为空**
确认 ffmpeg 已安装并在 PATH 中：`ffmpeg -version`。Vosk 中文模型需存在于 `models/vosk-model-cn-0.22/` 目录下。

**Q: 前端页面样式异常**
前端依赖 CDN 加载 Font Awesome、Chart.js、ECharts。确保网络可访问 `cdnjs.cloudflare.com` 和 `cdn.jsdelivr.net`。

**Q: 如何更换 AI 模型**
编辑 `app/services/baichuan_service.py`，将 `model` 参数从 `qwen-turbo` 改为其他百炼支持的模型（如 `qwen-plus`、`qwen-max`）。

**Q: 数据库在哪里？如何重置？**
数据库文件为项目根目录的 `zhiyu.db`（SQLite）。删除该文件后重启服务即可自动重建。

## 安全说明

- `.env` 包含 API 密钥，**禁止提交到公共仓库**（已加入 `.gitignore`）
- JWT `SECRET_KEY` 在生产环境中应使用强随机字符串
- CORS 默认限制为 `localhost`，部署公网时需更新 `app/main.py` 中的 `allow_origins`
- 生产环境建议在 Nginx / Caddy 反向代理后运行，启用 HTTPS
