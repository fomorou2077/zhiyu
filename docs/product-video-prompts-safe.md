# 知舆产品视频 — 过审版AI提示词（11镜全量替换）

## 改写原则

原版被拒 → 改后方案：
- "科幻风格/赛博朋克" → "现代科技感/干净的数字画面"
- "全息投影" → "大型数据展示屏幕"
- "红色/刺眼/风暴/撕裂/碎片" → "暖橙色/蓝色/汇聚/分散/信息卡片"
- "绝望/崩溃/失控" → "担忧/困惑/忙碌"
- "负面/危机" → "信息涌入/数据增长"
- 去掉所有暴力隐喻（刺穿/撕碎/风暴）
- 情绪描述从极端负面→中性适度
