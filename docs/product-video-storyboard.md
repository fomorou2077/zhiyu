# 知舆 ZhiYu — 1分钟产品场景视频 · 完整分镜与AI生成指南

## 基本信息

- 总时长：60秒
- 视觉风格：AI生成/CGI，电影级质感，深色科技色调
- 叙事结构：痛点 → 解决方案 前后对比
- 音频：专业男/女声旁白 + 背景音乐
- 画面比例：16:9 横屏
- 分辨率：1920×1080 或 4K

## 角色设定

### 角色A：自媒体创作者「小林」
- 身份：30万粉丝的科技类博主
- 形象：25-30岁，现代都市着装，戴眼镜，工作台有双屏显示器和拍摄设备
- 痛点：发布了一条有争议的视频，评论区失控，被断章取义截图疯传
- 情绪弧线：焦虑→无助→使用知舆后→冷静→掌控

### 角色B：企业公关总监「苏总」
- 身份：某消费品牌公关部负责人
- 形象：35-40岁，干练职业女性，开放式办公室/会议室场景
- 痛点：品牌负面舆情突然爆发，团队加班应对，信息碎片化
- 情绪弧线：压力爆表→手忙脚乱→使用知舆后→从容→自信

## 关键技术注意事项

1. **角色一致性**：小林和苏总需要在多个镜头中出现，AI生成时需要保持面部特征一致。建议：先用Midjourney生成角色设定图，再用"reference image"或"character consistency"功能约束后续生成。

2. **UI界面叠加**：镜头07-09中的知舆产品界面建议用After Effects后期合成，而不是AI直接生成，这样界面内容更可控，且可以精准展示产品实际功能。

3. **文字准确**：所有产品名称"知舆"、功能名称、数据指标等建议后期叠加文字层，不要依赖AI生成准确的汉字。

4. **色调统一**：全片保持深色科技风基调——青色(#00f2ff)为品牌主色，紫色(#8b5cf6)为辅色，红色(#ef4444)仅用于危机/负面提示。
